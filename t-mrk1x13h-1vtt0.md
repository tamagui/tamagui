## F0 read-only preflight: compile-only DOM v1\n\n### Dependency/order verdict\n\nF0 must remain behind the integrated E2/E3/E4 baseline. Implement one shared IR structural pass called by both frontends; do not add a Babel/static-extractor DOM path or separate Vite/Metro transforms. Required order is: user syntax/plugins -> JSX/jsx/jsxs/createElement normalization -> F0 native DOM rewrite/import injection -> ordinary Tamagui component/style analysis. Web selects the no-op adapter and preserves literal tags. Running F0 after Tamagui extraction is a blocker because literal DOM tags would bypass token/media/pseudo analysis.\n\n### Exact existing seams\n\n- plans/dom-mode.md:34-68 is canonical for tag classes/rewrite; :70-83 limits runtime behavior; :98-105 defers ScrollView, select/options, forms, broad ref emulation, dynamic-string rescue, and RSD.\n- code/core/web/src/styled.tsx:53-150 and styledHtml():164-205 contain a broader, web-oriented text-tag/type table. It disagrees with F0 (notably p/headings are absent from textLikeElements), so it is evidence/reference, not the canonical F0 table.\n- code/core/web/src/eventHandling.ts:10-21 maps Tamagui onPress -> DOM onClick. F0 needs the inverse DOM onClick -> native press adapter and must not reuse this direction blindly.\n- code/core/web/src/eventHandling.native.ts:102-148 already documents TextInput/composite press delivery constraints; DOM input/button wrappers must remain ordinary known Tamagui/native components so this path is not bypassed.\n- code/core/core/src/createOptimizedView.native.tsx:20-143 contains useful pure aria/id/role/tabIndex mappings and the TextAncestor boundary, but it is private, mutates props, hardcodes RCTView, and is reached by the runtime useChildren hook at core/src/index.tsx:210-223. Do not use it for runtime child repair. Extract/share only pure mapping semantics if worthwhile.\n- code/core/web/src/helpers/useRenderElement.tsx:32-41 deliberately ignores lowercase render strings on native. Compiler-rewritten @tamagui/dom/native symbols bypass this correctly; no runtime lowercase-tag fallback should be added.\n- code/ui/input/src/Input.native.tsx:18-150 and code/ui/image/src/Image.native.tsx:1-6 prove existing host prop conversions, but depending on the styled UI packages would import their public component policy/aesthetics. @tamagui/dom should own minimal behavior wrappers over core + RN hosts instead.\n- RSD reference confirms the selected layout delta: flex containers default row/stretch/auto/1/nowrap/flex-start; block flow emulation uses column/stretch/auto/0/nowrap/flex-start. Copy only the explicitly selected conformance rows, never the RSD runtime or StyleX subsystem.\n\n### Smallest package/source slice\n\nCreate code/ui/dom as @tamagui/dom with three isolated surfaces:\n\n- src/contracts.ts + export ./contracts: dependency-free frozen data/types for the exact V1 tags, tag kind, native symbol, default semantic role/heading level, permitted attributes/events, nesting constraints, and diagnostic codes. Compiler imports only this subpath; it must not pull React, core, or react-native.\n- src/native.tsx + export ./native: named behavior primitives (DomView, DomText, DomButton, DomAnchor, DomImage, DomInput, DomTextarea, plus DomLiteralText). Compiler injects only used names. These may depend on @tamagui/core and peer React/RN.\n- src/index.ts: public contract/types only. Add an opt-in JSX type surface for the exact supported intrinsic tags if the integrated native TS fixture proves React Native projects cannot typecheck literal DOM tags; do not globally type every HTMLElement.\n\nThe minimal first proof is div/span/button, because it exercises View/Text classification, literal wrapping, an event, a role, import de-duplication, and web no-op. The mapping table should still encode the complete locked V1 set up front. F0 is not complete until all plan tags and img/input/textarea/a behavior pass.\n\nNative primitives must never inspect children by type. The compiler alone wraps direct string and numeric literals in DomLiteralText; expression containers, spreads, conditionals, arrays, and component children remain untouched. Dynamic raw text under DomView must retain the RN failure.\n\n### Contract details to lock before code\n\n- Layout: freeze exact block/flex default rows; apply them only to DomView-backed rewritten elements, never ordinary View. Do not import browser UA cosmetics wholesale. Decide separately whether strong/em/code/headings receive semantic font defaults.\n- Text inheritance: one minimal context for the selected inheritable text keys across View-backed descendants; compiler propagation for static values, context only for dynamic values. Reuse Tamagui value resolution, not an RSD CSS/custom-property engine.\n- Accessibility: pure map for id -> nativeID, role/default tag roles, aria-label/labelledby/hidden/live/state/value, tabIndex -> focusable, headings -> heading role + level, ul/ol/list/li roles, img alt -> accessibilityLabel.\n- Events: onClick invokes a small DOM-like supported event shape and maps to onPress. For anchors, call user onClick first and Linking.openURL(href) only if not prevented; disabled button suppresses press/focus. Warn/bail for unsupported bubbling/capture/default-action claims.\n- Inputs: only text/password/email/tel/number/url/search conversions, value/defaultValue, disabled/readOnly, placeholder, onChange/onInput, focus/blur, and textarea multiline/rows. Unsupported input types diagnose; no form semantics.\n- Unknown tag, statically known invalid attr/nesting, or structurally uncertain spread requiring semantic mapping must produce a stable native diagnostic and bail rather than silently guess.\n\n### Compiler owner contract\n\nFinal filenames must be chosen on the integrated E2/E3/E4 tree; the current baseline does not contain that shared IR. The owner symbol should be a target-aware IR pass such as rewriteDomElements(program, {target, diagnostics}) returning rewritten IR + required imports. E3/E4 only select target and forward diagnostics/cache dependencies. Mapping contract version/hash must participate in transform cache keys so table edits invalidate Vite HMR and Metro's content cache.\n\nImport injection must be collision-safe, deterministic, de-duplicated, preserve directives/import ordering, and cover source JSX plus compiled jsx/jsxs/createElement identically. No old code/compiler/static/extractToNative fallback.\n\n### Smallest conformance/gates\n\n1. Shared IR snapshots: same fixture as source JSX, jsx/jsxs, and createElement. Web output retains literal tags/no @tamagui/dom import. Native output uses minimal named imports, maps attrs/events, and wraps only direct string/number children.\n3. Native package renderer: host JSON for block/flex defaults, text inheritance through a DomView, heading/list/image accessibility, button/anchor press and preventDefault, input/textarea change/focus. Assert dynamic View text still throws/fails.\n5. Bundle/pack gates: no react-strict-dom/StyleX, React.Children, child string scan, or compiler dependency in native runtime; contracts import has zero runtime package graph; ESM/CJS/react-native exports and packed consumer resolve.\n7. Regression/perf: ordinary Tamagui View/Text output and render benchmark unchanged when DOM mode is off; cache/HMR edits to contract and fixture invalidate exactly affected modules.\n\n### Blockers/hazards\n\n- Hard blocker: no canonical integrated E2/E3/E4 owner path yet; do not implement against legacy static extraction or active E3 WIP.\n- The rewrite-before-style-analysis hook must exist in both frontends.\n- Keep ./contracts dependency-free or compiler evaluation will pull core/RN and create package-cycle/startup risk.\n- Do not reuse styledHtml's broader/mismatched tag table.\n- Native intrinsic JSX typing and ref types need an explicit compile-only fixture; HTMLElement ref parity is deferred.\n- Label association, browser bubbling, target/download, and non-text input behavior must be diagnosed/deferred unless the locked conformance table explicitly includes them.
