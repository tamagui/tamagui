<IntroParagraph>
  Tamagui installs with no bundler configuration on web or native. Start small,
  and add the compiler and bundler plugins once the basics work.
</IntroParagraph>

The fastest start is a starter template:

```bash
npm create tamagui@latest
```

## Requirements

- **React 19+**
- **TypeScript 5+**
- **React Native 0.81+** with the New Architecture enabled, for native apps.
  Tamagui uses newer style features such as `boxShadow` and `filter`. On web
  there are no version restrictions.

## Install

Install the full UI kit:

```bash
yarn add tamagui @tamagui/config
```

Or install only the style library. The `tamagui` package is a superset of
`@tamagui/core`, so anywhere the docs reference core you can use either:

```bash
yarn add @tamagui/core @tamagui/config
```

## Choose a styling frontend

Tamagui has two ways to write styles. Both produce the same output, and the
choice is per import path, so you can mix them later. Pick one to start.

<MDXTabs.Content value="props">

Typed style props on semantic `html.*` elements. This is the recommended base
for new apps. It reads like React Native, stays close to the web, and needs no
extra package.

```tsx fileName="App.tsx"
import { TamaguiProvider, createTamagui, html } from 'tamagui'
import { defaultConfig } from '@tamagui/config/v6'

const config = createTamagui(defaultConfig)

declare module 'tamagui' {
  interface TamaguiCustomConfig extends typeof config {}
}

export default () => (
  <TamaguiProvider config={config} defaultTheme="light">
    <html.div width={200} height={200} backgroundColor="background" />
  </TamaguiProvider>
)
```

Continue with [Components](/docs/intro/components) and
[Styling](/docs/intro/styles).

</MDXTabs.Content>

<MDXTabs.Content value="tailwind">

Tailwind utility classes on `className`, extracted to atomic CSS on web and
resolved to native styles on iOS and Android.

```bash
yarn add @tamagui/tailwind
```

```tsx fileName="App.tsx"
import { TamaguiProvider, createTamagui } from 'tamagui'
import { html } from '@tamagui/tailwind'
import { defaultConfig } from '@tamagui/config/v6'

const config = createTamagui(defaultConfig)

declare module 'tamagui' {
  interface TamaguiCustomConfig extends typeof config {}
}

export default () => (
  <TamaguiProvider config={config} defaultTheme="light">
    <html.div className="w-[200px] h-[200px] bg-background" />
  </TamaguiProvider>
)
```

Continue with [Tailwind](/docs/core/tailwind).

</MDXTabs.Content>
</MDXTabs>

You usually export the config from a `tamagui.config.ts` file. See
[Configuration](/docs/core/configuration) for what goes in it.

Set your root theme with the `defaultTheme` prop on `TamaguiProvider` rather
than wrapping the app in `<Theme>`. That keeps the
[`fastSchemeChange` setting](/docs/core/settings) working on native and lets
light and dark switch through media queries during SSR on web.

That is the whole setup:

<Preview>
  <DemoButton />
</Preview>

```tsx class=preview line=5
import { Button } from 'tamagui'

export default function Demo() {
  return <Button theme="blue">Hello world</Button>
}
```

Every feature works at runtime, so nothing above depends on a bundler plugin.
When you are ready for production, [set up the compiler](/docs/intro/compiler-install)
for smaller bundles and faster renders.
