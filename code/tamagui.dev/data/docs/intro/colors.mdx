<IntroParagraph>
  Explore the default color palettes and learn how to configure custom palettes
  with `@tamagui/colors` or Config v6.
</IntroParagraph>

Tamagui defaults to Tailwind-aligned colors in `@tamagui/config/v6`, while also supporting Radix palettes via `@tamagui/colors`. For configuring custom color palettes and recipe-generated adaptive themes, see the [v6 Colors guide](/docs/core/config-v6-colors).
