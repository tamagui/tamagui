<IntroParagraph>
  Unspaced opts individual children out of spacing applied by an older Tamagui
  `space` container.
</IntroParagraph>

The `space` property is deprecated, but Unspaced remains available for code that
has not moved to `gap`.

To leave some children unspaced inside a `space` container:

## Usage

```tsx
import { Unspaced, html } from '@tamagui/core'

export default () => (
  <html.div position="relative" space>
    <html.div width={20} height={20} />
    {/* space */}
    <html.div width={20} height={20} />
    {/* no */}
    <Unspaced>
      <html.span position="absolute">Some absolute positioned text</html.span>
    </Unspaced>
  </html.div>
)
```

If you want the item to be visually hidden as well as unspaced, see
[VisuallyHidden](/ui/visually-hidden), which uses Unspaced but also hides the contents in an accessible manner.
