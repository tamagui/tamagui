## Installation

Spinner is already installed in `tamagui`, or you can install it independently:

```bash
npm install @tamagui/spinner
```

Spinner extends React Native's [ActivityIndicator](https://reactnative.dev/docs/activityindicator), which only accepts `small` or `large`, so those are the only sizes.

## Usage

```tsx
import { Button, Spinner } from 'tamagui'

export default () => <Spinner size="large" color="green-10" />
```
