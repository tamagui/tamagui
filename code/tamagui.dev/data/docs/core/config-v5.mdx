---
title: 'Config v5 (Tamagui v2)'
description: Legacy configuration retained only for Tamagui v2 applications
---

<Notice theme="yellow">
  Config v5 and `@tamagui/theme-builder` belong to Tamagui v2. Their package
  entries are not available in Tamagui v3. Keep all Tamagui packages on v2 if
  your application must retain that theme system.
</Notice>

New and migrated v3 applications should use
[`@tamagui/config/v6`](/docs/core/config-v6):

```tsx fileName="tamagui.config.ts"
import { defaultConfig } from '@tamagui/config/v6'
import { createTamagui } from 'tamagui'

export const config = createTamagui(defaultConfig)
```

Read the [v3 upgrade guide](/docs/guides/how-to-upgrade#theme-migration) for the
11-step color ramp, surface-to-level mapping, and recipe-tree replacement for
the old builder options.
