---
title: Shorthands
description: Map short prop names to any style property.
---

<IntroParagraph>
  Shorthands give frequently used style props shorter names, such as `px` for
  `paddingHorizontal`.
</IntroParagraph>

Define them on `createTamagui` under `shorthands`. Each key maps to one style
property:

```tsx fileName="tamagui.config.ts"
// as const keeps the keys literal so types flow through
const shorthands = {
  ac: 'alignContent',
  ai: 'alignItems',
  als: 'alignSelf',
  bg: 'backgroundColor',
  br: 'borderRadius',
  f: 'flex',
  m: 'margin',
  px: 'paddingHorizontal',
  w: 'width',
  // ...
} as const

export const config = createTamagui({
  shorthands,
  // ...
})
```

Shorthands work everywhere a style prop works: inline props, `styled`, variants,
media and pseudo clauses, and the compiler flattens them the same way it flattens
the long form.

```tsx
<html.div br="lg" bg="background" px="4" />
```

[`@tamagui/config/v6`](/docs/core/config-v6) ships with Tailwind-aligned names such
as `w`, `h`, `p`, `m`, `px`, `rounded`, `items`, and `justify`. Spread
`defaultConfig.shorthands` to extend them.

## Only allowing shorthands

Set `settings.onlyAllowShorthands` to remove the long-form prop types for every
property that has a shorthand. Autocomplete then shows one spelling per property:

```tsx fileName="tamagui.config.ts"
export const config = createTamagui({
  shorthands,
  settings: {
    onlyAllowShorthands: true,
  },
})
```

This is type-level only. The runtime still accepts the long form.

### Upgrading to 3.1

Version 3.1 repairs declarations that could allow long-form props through styled
components, compound components, and wrappers even when `onlyAllowShorthands` was
enabled. Code that relied on that regression can now report a type error. Use the
configured shorthand instead:

```tsx
// before, with an items shorthand configured for alignItems
<YStack alignItems="center" />

// after
<YStack items="center" />
```

Setting `onlyAllowShorthands: false` continues to allow both forms. Plain style
objects such as `contentContainerStyle` use React Native style property names,
for example `paddingBottom`, rather than Tamagui shorthands.
