## What is in it

82 commits from `origin/main` through `50b7a10f98` (v2.6.3).

**The font fix (`ab66499598 fix(static): preserve conditional font variants`)
has nothing to port.** v3-beta deleted the whole v2 babel extractor, so the
`createExtractor`/`normalizeTernaries` half had nowhere to land; the
`concatClassName` `font_` dedup merged on its own. The v2 bug does not
reproduce in v3, but not for a good reason: see the hard rule in
`plans/v3-beta-campaign-plan.md`. v3 refuses to compile the case at all
(`local/dynamic-style-value`, whole element to runtime, web and native both),
where v2 lowered it into per-branch output. That is a parity regression and is
on the list. `tests/fonts.web.test.tsx` was rewritten to pin what v3 does today
so the change is visible when it is fixed.

**The media-state half of `a4ce4e9bdb fix(compiler): share media and token
state` was deliberately not ported.** It puts media containers on `globalThis`.
v3 asserts the opposite in `static-tests/tests/loadTamagui.web.test.tsx`: the
compiler's boundary copy of core must keep its own `mediaQueryConfig` so that
loading a user's config does not contaminate the compiler's own. The merged
suite caught this. The token half of the same fix is ported, through v3's
existing global-config channel, which closes the same duplicate-copy hole
without changing object identity.

**Other resolutions worth knowing:** rewritten or renamed packages took the v3
side; the PromoBanner removal was adopted and `Header.tsx` keeps v3 flat
shorthand with the banner terms dropped; `code/sandbox` pinned to `one@1.21.13`
to match the rest of the workspace; 12 straggler packages bumped 2.5.1 -> 2.6.3
so the workspace sits on one version.
